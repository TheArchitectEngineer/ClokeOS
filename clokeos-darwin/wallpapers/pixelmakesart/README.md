# Wallpapers by Pixel Makes Art

Full-resolution originals (6439 x 4961 px, JPEG as delivered) of the 13 artworks by
[Pixel Makes Art](https://www.instagram.com/pixelmakesart), used in ClokeOS with permission.
`artNN.jpg` here matches `artNN.png` in `overlay-desktop/Library/ClokeOS/Wallpapers/`, which ClokeOS ships
at 3840 px width (4K). The originals are for displays larger than 4K; later releases are meant to download
them on such displays instead of shipping them in every image.
